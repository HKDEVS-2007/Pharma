How Syncing Works

The Admin PC acts as the single source of truth. All data transactions are processed there.


User PCs act as interactive windows. They don't store data locally but fetch it instantly from the Admin PC.


Network Requirements: All devices must be on the same local network (WiFi or Ethernet) to communicate.

Network Tip

If connection fails, check if the Windows Firewall is blocking port 7272 on the Admin PC.
